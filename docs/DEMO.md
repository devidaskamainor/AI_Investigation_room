# Five-minute showcase

Generate the three fixtures with real Gemini credentials: `npm run fixtures:generate`. This makes real text and image calls and consumes quota. It exports only after the normal validator and blind solver pass. Keep fixture JSON on the server. Enable DEMO_MODE only in development; restart API and worker.

1. Show the landing page and fiction notice.
2. Create a new case from an audience premise; leave its real generation progress visible.
3. Open a labelled pre-generated demo from the dashboard.
4. Read a chat, zoom a photo and scrub a CCTV reconstruction.
5. Pin a clue, write a note and submit a theory. Demonstrate the limited wrong-attempt nudge.
6. Show the reveal, evidence chain, timeline and score.
7. Return to the live-generated case and show the automated leak, ownership and validator tests.

This workspace does not claim real-pipeline fixtures or real-provider reliability numbers until those commands have actually succeeded. `npm run stats` reports null, not an invented percentage, when no finished generation data exists.
